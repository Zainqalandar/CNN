# CNN Website Clone

A responsive CNN-inspired news homepage built from scratch using only HTML, CSS, and vanilla JavaScript. This project was created for frontend practice, with a focus on reproducing a modern news website layout, navigation, content sections, and responsive styling.

> This is an educational UI clone and is not affiliated with or endorsed by CNN.

## Features

- CNN-inspired dark navigation bar and branding
- News category navigation with a More dropdown
- Responsive news homepage layout
- Featured stories, top stories, latest news, entertainment, sports, and video sections
- Search panel opened from the menu interaction
- Expandable edition/navigation section
- Responsive footer with multiple news categories
- Local image and video assets
- Mobile-friendly CSS layouts

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts and Material Symbols

## Project structure


## Run locally

No build tools or dependencies are required.

### Option 1: Open directly

Open `Mainpage.html` in a browser.

### Option 2: Use VS Code Live Server

1. Open the `CNN` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `Mainpage.html`.
4. Select **Open with Live Server**.

## JavaScript interactions

- The hamburger button toggles the search and account navigation panel.
- The edition control expands and collapses edition options.
- Navigation dropdown styles provide additional category links.

## Learning goals

This project demonstrates:

- Semantic HTML page organization
- CSS Grid and Flexbox layouts
- Responsive design with media queries
- Reusable styling across multiple sections
- DOM selection and class toggling with vanilla JavaScript
